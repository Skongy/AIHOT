# 管理员用户活跃分析

入口 `/admin/analytics`；只读接口 `/api/admin/analytics?days=7|30|90`，复用现有管理员会话校验，响应禁止缓存。公开页面仍通过原有 `/api/site/visit` 上报，不增加第三方统计脚本或网络服务。

## 数据口径

- 浏览器首次访问时用 Web Crypto 生成128位随机ID，存于本站 localStorage。上报只带匿名ID、页面路径、来源站点；不发送Cookie、查询参数、问答内容。服务端只存带业务命名空间的SHA-256摘要，不以IP当作访客ID、不进行浏览器指纹识别。
- DAU和昨日活跃按北京时间自然日去重；WAU为含今天近7个自然日的去重访客；MAU为含今天近30日的去重访客。不是把每天DAU相加。
- PV按成功记录的页面浏览累计，包括刷新和前进后退，查询参数单独变化及预取不累计。ID无法持久保存时，不创建一次一变的ID，以免伪增DAU；原IP访问记录仍按原规则保留。
- 新增访客按匿名ID首次被服务端记录的日期统计，不代表真实自然人或新注册用户。来源/设备分布按每位访客在所选期间首次活跃的当日归因统计，各分布人数之和等于范围UV；来源只保存域名，缺来源或站内来源计“直接访问 / 未提供”，来源超8项归并尾部为其他来源。
- 新/回访比例按所选范围区分：首次记录在范围内为新访客，首次记录早于范围起点为回访。范围内多次访问的新访客不会同时计入回访。
- 功能模块根据真实前端路由映射，文章与原文阅读归新闻阅读，热点详情归热点，日报与周/月报分别汇总。模块UV各自去重，不能相加当总UV；页面访问不代表问答发送或收藏成功等操作。
- 复用已安装isbot识别已知爬虫；排除后台、API、静态资源、健康检查、未知页面路由。只统计执行JavaScript且允许本地存储的浏览器；拦截器、限流、网络错误及伪造信息会影响准确性，不作为审计或计费依据。

## 存储与保留期

5条单语句在线迁移：

- `0075_analytics_visitors.sql`：匿名ID摘要及首次/最后访问时间。
- `0076_analytics_days.sql`：按北京时间日/匿名ID聚合的PV、当日首次来源、设备类型；主键同时用于DAU去重。
- `0077_analytics_modules.sql`：按日/匿名ID/模块的PV；外键指向访客日，事务中与总PV一起更新。
- `0078_analytics_visitor_days_idx.sql`：访客/日期并发索引，支持范围去重查询及保留清理。
- `0079_analytics_first_seen_idx.sql`：首次访问时间并发索引。

复用每日retention任务，先清理模块、再清理访客日，保留含当天的90个自然日；连续365天不活跃且无剩余日记录的匿名ID被清理。原site_visits含IP记录仍为30天，未扩大原始数据保留期。新的按日表不保存IP、原始User-Agent、完整来源URL和浏览记录明细。

每次上报三次有主键的upsert、一个短事务；保持既有每IP/全局上报频率和并发限制。后台读取为限制90天的只读一致性事务；不在访问时调用模型或采集外部资讯。首次部署迁移先于新服务启动。

## 首次上线及限制

旧访问记录没有匿名ID，不能据其补造历史DAU。趋势中首次统计日前留空，昨天尚未采集时看板显示破折号；7/30天指标只包含已记录部分，并在页面明示覆盖范围。没有预置或回填模拟访问数据。

换浏览器/无痕模式/清理localStorage会成为新ID；同一人在不同设备会算多个访客，ID共享或被复制也可能合并计数。ID匿名且不与账户绑定。原隐私说明按用户此前“不要更改隐私说明”的要求保留，现有说明与新增统计能力存在表述不一致，应由站点运营者后续确认。

测试含真实PostgreSQL的日界线、并发PV、WAU/MAU去重、分布守恒、保留期、权限及原访问记录回归；浏览器CI使用仅位于测试文件中的响应样本，本地额外以真实API/隔离数据库验证展示。所有测试样本仅进入本地/CI隔离库，不注入生产数据。
