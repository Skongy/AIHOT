# GAMEHOT AI 问答

问答页 `/ask` 面向玩家的三个任务：快速补课、追踪游戏、看懂事件。示例仅填入输入框，点击发送才创建任务；读页面、恢复对话、读取文章上下文均不调用模型。

## 查询与追问

- 八个只读工具：近期资讯、搜索、热点、事件、入选解释、上榜解释、日报、文章摘要。
- 近期与搜索支持 `1h / 24h / 7d / 30d / all`；可用 `from / until` 指定日期或带时区的 ISO 时间。日期按北京时间，开始含、日期型结束含当天，ISO 结束不含该时刻。
- 时间筛选在公开读取层执行；游标固定首屏的范围与查询，按时间和文章 ID 翻页。每页最多 30 条，有下一页时不能声称已统计全部。
- 搜索复用 `industry/taxonomy.ts` 的名称与别名。先查精选，无结果才扩到全部；具名搜索无结果不使用无关近期资讯补齐。
- 连续追问保留最近消息及先前出处的文章/事件 ID 映射。旧轮编号不直接跨轮使用，助手须重新读取工具登记本轮来源。
- 详情页“问问这篇资讯”进入 `/ask?article=…`；展示标题并附带文章路径，点击发送后由文章工具读取公开摘要。

## 来源与回答

回答使用 React 渲染有限 Markdown（标题、列表、加粗、代码、登记链接），不渲染原始 HTML、远程图片或 iframe。编号可展开并定位对应来源；来源显示媒体、北京时间日期及阅读链接。

引用检查识别不存在的编号、缺失引用和裸链接；**不执行事实真伪或语义蕴含验证**。提示词要求逐项引用、区分官方消息/媒体报道/传闻，前端不显示“事实已核实”。恢复历史、快照和终态流重验公开范围，撤回或降级来源使原轮回答失效。

## 交互与开关

中文输入法选词时 Enter 不发送，Shift+Enter 换行。生成期间可起草下一个问题；上翻阅读停止跟随，提供“回到最新回答”。发送故障重试复用请求 ID，恢复快照后续接；会话过期重新建立。停止生成只提交取消请求，不自动追加付费重试。

`MODEL_CALLS_ENABLED` 关闭时页面提前说明暂未开放，发送接口拒绝建任务。原有付费回执、预算、每任务调用限制与生产开关保持原规则。

## 视觉与验证

沿用站点瓷白/墨色/金铜色语义变量；标题使用站点展示字体、正文使用无衬线，内容列宽 760px。输入区为主入口，三个提问方向为次入口，回答和来源分层。只对焦点、按压和真实等待状态使用轻量动效，尊重减少动态效果设置。

欢迎页入场参考 [Motion Primitives Animated Group](https://motion-primitives.com/docs/animated-group) 的分组错峰和 [Magic UI Blur Fade](https://magicui.design/docs/components/blur-fade) 的轻柔显现节奏，用原生 CSS 实现标题两行、说明、输入区、提问入口依次浮入。约 1.2 秒结束，仅动画 transform/opacity，不增加动画依赖或持续漂浮；手机缩小位移，减少动态效果设置下直接显示。会话恢复完成后统一挂载欢迎内容与输入区，避免加载前后重复入场；输入框获得焦点会立即结束自身入场，打字及流式更新不会重播。

测试覆盖精确时间与历史边界、别名、稳定翻页、撤回、追问出处映射，以及浏览器输入、发送幂等、引用、刷新、手机与深色布局。测试使用本地固定材料和模型替身，不把它们当作真实新闻或真实模型质量评测。
