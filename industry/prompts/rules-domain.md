
【游戏领域翻译规则 — 本平台的内容都是游戏资讯，读者是国内玩家，严格遵守】

1. 游戏名**优先用 Steam 国区或社区通用简体中文译名**：
   - 本站种子游戏固定译名：以撒的结合：重生（The Binding of Isaac: Rebirth）、杀戮尖塔 2（Slay the Spire 2）、喵喵的结合（Mewgenics）、博德之门 3（Baldur's Gate 3）
   - 有 Steam 国区中文名或通行简体译名的，用该中文名；首次出现可双标「喵喵的结合（Mewgenics）」，后续选一种保持一致
   - 没有通行中文名的，保留英文原名，不自行意译（不要把 "Hollow Knight: Silksong" 随手译成别的名字）
   - 系列作品的编号和副标题一字不改（"艾尔登法环 黑夜君临"、"Call of Duty: Black Ops 7"）

2. 歧义默认值：以下词在中文有非游戏歧义，**一律按游戏含义翻译**：
   - Patch = 补丁 / 更新；Update = 版本更新
   - Season = 赛季；Battle Pass = 通行证；Banner = 卡池
   - Expansion = 资料片；DLC 保留英文
   - Early Access = 抢先体验；Closed Beta / Open Beta = 封闭测试 / 公开测试；Soft Launch = 小范围上线
   - Live Service = 长线运营；Gacha = 抽卡
   - Roguelike / Roguelite / Soulslike / Metroidvania 保留英文，可加通用中文说法（类魂、类银河恶魔城）
   - Nerf / Buff = 削弱 / 增强
   - Delist = 下架；Sunset / End of Service = 停服

3. 以下专有名词**一律保留英文原文**，不翻译：
   - 平台与商店：Steam / Epic Games Store / PlayStation / PS5 / Xbox / Game Pass / Switch / Switch 2 / App Store / Google Play
   - 通用缩写：PC / DLC / MMO / MMORPG / MOBA / FPS / TPS / RPG / ARPG / SLG / RTS / NPC / PvP / PvE / DAU / MAU / TGA / E3 / CJ（ChinaJoy）
   - 厂商英文名在没有通用中文名时保留英文；有通用中文名的用中文（索尼、任天堂、微软、腾讯、网易、米哈游、鹰角网络、游戏科学、拳头游戏、育碧、卡普空、万代南梦宫）

4. 国内语境：
   - "版号"指国家新闻出版署的网络游戏审批，不译成 license 以外的说法
   - 国服、外服、港服、日服、美服照原文保留
   - 人民币价格保留"元"，外币保留原币种符号和数字，不自行换算

5. 代码 / 命令 / URL / 数字单位 **一字不改**保留：
   - URL 原样
   - 版本号（2.6 / 3.0 / 第 12 赛季）、价格（298 元 / $69.99）、日期、在线人数、销量、评分（Metacritic 92）必须保留原文的阿拉伯数字和单位，不改写成模糊的中文数量词

6. 繁体和外文来源**一律输出简体中文**：
   - 巴哈姆特 GNN、PlayStation 中文博客、任天堂香港是繁体中文：标题和摘要转成简体，用语按大陆习惯（遊戲→游戏、伺服器→服务器、實況→直播、上市→发售），游戏名仍按第 1 条用国服或官方简体译名
   - 任天堂日本（日文）、Xbox Wire、HLTV、LoL Esports、网易投资者关系（英文）同样输出简体中文；台服、港服、日服独有的消息要写明是哪个服，不当成国服消息

7. Steam 新闻与商店页：
   - Steam 新闻 RSS / 商店页常中英混排：输出仍用简体中文；补丁号、Build、成就名等专有符号保留原文
   - 写明平台时优先写 Steam；若同时登陆主机，可并列写 PS5 / Xbox / Switch，不要把主机独占消息写成 Steam 可玩
