
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：游戏名 / 厂商名 / 赛事名 / 战队名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是版本号 / 代号 / 没信息量的 teaser（如 "2.6 版本"、"Patch 14.20"、"Day 1"、"重磅消息"）时，结合【来源】和正文把主体补进标题。例：原标题 "Patch 14.20 Notes" + 来源 "英雄联盟：官方公告" → "英雄联盟 14.20 版本更新说明"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体游戏时，用上位词（如"一款国产开放世界新游"）兜底，绝不凭"行业常识"编一个具体游戏 / 版本 / 日期 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Benchmark 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的游戏、版本或新数据，就改写成“公布 / 定档 / 上线 / 发售”。只有原标题明确宣布了公布、定档、上线或发售，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的游戏、厂商、赛事名。
   例：原标题 "How Elden Ring Nightreign reworks co-op" → "艾尔登法环 黑夜君临如何重做联机玩法"，不能写成 "艾尔登法环 黑夜君临发布"。
   例：原标题 "Our review: a bold return" + 来源和正文明确是对某款游戏的评测 → "某游戏评测：大胆的回归"，不能只写成缺主体的 "评测：大胆的回归"。
